# claude-plugins

My personal collection of [Claude Code](https://code.claude.com) plugins,
distributed as a plugin marketplace.

## Install

Add the marketplace once, then install any plugin by name:

```
/plugin marketplace add kelvindecosta/claude-plugins
/plugin install <plugin>@kelvindecosta
```

## Plugins

| Plugin                                                          | Description                                                                                  |
| --------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| [macos-audio-notifications](plugins/macos-audio-notifications/) | **macOS only.** Spoken notifications for Claude Code lifecycle events via the `say` command. |
